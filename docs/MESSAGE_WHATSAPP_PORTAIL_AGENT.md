# Message WhatsApp — Rappel Portail Agent

> Message de rappel à diffuser aux agents avant le lancement de la campagne d'approvisionnement Data.

---

📋 **DATA APPRO — RAPPEL PORTAIL AGENT**

Bonjour à tous,

La campagne d'approvisionnement Data approche. Voici un rappel pour suivre votre statut en temps réel et faire valoir vos droits.

🔹 **Le Portail Agent, c'est quoi ?**
C'est votre espace personnel pour consulter l'état de votre approvisionnement Data : quota attribué, statut de la transaction, accusé de réception — le tout en temps réel, sans compte ni mot de passe.

🔹 **Comment y accéder ?**
1. Rendez-vous sur : **https://data-appro.pages.dev/portal**
2. Saisissez votre **numéro de téléphone Airtel** (format : 06 XXX XXXX)
3. Vous verrez instantanément :
   - Le statut de la campagne (en attente, en cours, terminée)
   - Votre quota Data attribué
   - Le statut de votre transaction (envoyé, confirmé, échec)

🔹 **Une question ? Une réclamation ?**
Sur le portail, une **fenêtre « Réclamation »** est à votre disposition. Saisissez un **sujet** et un **message**, puis envoyez. Votre message arrive directement à l'administrateur, qui le lit et **vous répond** dans les meilleurs délais.

Vous pouvez y signaler par exemple :
- Votre numéro n'est pas reconnu sur le portail
- La transaction a échoué alors que la campagne est lancée
- Votre quota Data est incorrect
- Tout autre souci lié à votre approvisionnement

⚠️ **Important :** Le portail est accessible 24h/24. Vous n'avez besoin que de votre numéro de téléphone — pas de compte, pas de mot de passe.

Pour toute question ou réclamation, écrivez-nous directement depuis la fenêtre **« Réclamation »** du portail. L'administrateur lira votre message et vous répondra.

Cordialement,
**L'équipe Data Appro**
